# CurScript

A scripting language allowing you to automate the movement of your cursor.



### How to run:

Install python and the required dependencies

open "CurScript.py"



### How to use:

Once inside the program, you have 2 options.



#### Option 1: Run .curscript files

If you already have a .curscript file you want to use or need to test out if the program works,

* Type "run" and press enter
* Type the name of the file you want to run (file extension included)

CurScript already comes with a test file inside the "projects" folder



#### Option 2: Create your own .curscript files

* Type "learn" and text will show up detailing how to write curscript.
* Create a new text file and write these commands each on different lines, and with correct capitalization.
* Rename the file extension to ".curscript" (This is an optional step, but is recommended for proper file organisation)
